# Screenshots

Drop interface screenshots here and they will render in the root
[`README.md`](../../README.md) "Screenshots" section.

Expected filenames (referenced by the root README):

| File                  | Suggested content                                  |
| --------------------- | -------------------------------------------------- |
| `bot-start.png`       | `/start` screen with the main reply keyboard        |
| `bot-search.png`      | A film search result card — poster, rating, actions |
| `bot-library.png`     | Personal library: watchlist / favorites / history   |
| `bot-collections.png` | A user collection with films in it                  |
| `api-docs.png`        | The FastAPI Swagger UI at `/docs`                   |

Guidelines:

- PNG, cropped to the Telegram window / browser viewport — no desktop background.
- Keep each file under ~500 KB so cloning stays fast.
- Blur or replace any real personal data (usernames, avatars, ids, tokens)
  before committing — this repository is public.
